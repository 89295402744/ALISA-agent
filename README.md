# 🎙️ ALISA-agent

Локальный голосовой AI-ассистент для Windows на Python.

**Микрофон → распознавание речи → DeepSeek → голосовой ответ**

Проект находится в разработке.

---

## ✨ Возможности

- 🎤 Распознавание речи с микрофона
- 🤖 Работа с DeepSeek
- 🔊 Голосовые ответы
- 🗣️ Поддержка русского языка
- 🛑 Голосовое завершение работы

---

## ▶️ Запуск

Для работы используется локальный сервер FreeDeepseekAPI.

Запуск сервера:

**C:\FreeDeepseekAPI → npm start**

После запуска сервера:

**C:\chatAssistant → python "main alisa.py"**

Локальный API:

**http://127.0.0.1:9655/v1**
